# 🚀 Thiagarajan Hariharan — Cloud & AI Portfolio

A modern, responsive developer portfolio featuring 3D AI-generated project visuals and the interactive **GitHub Contribution Blaster** arcade game.

Live Site / Preview: [index.html](index.html) | Standalone Arcade: [contribution-blaster.html](contribution-blaster.html)

---

## 🌟 Features

### 🕹️ GitHub Contribution Blaster Arcade
- **Interactive Raygun Aiming & Recoil:** Custom cartoon SVG blaster tracking cursor physics and firing plasma bolts.
- **🚀 Tactical Nuke Strike Mode:** Scans the 52-week heatmap grid, paints targets with red `[ 🎯 X ]` lock-on brackets, and launches a ballistic cruise missile barrage with screen rumble and shockwaves.
- **Zero-Dependency 8-Bit Web Audio Engine:** Synthesizes laser pews, radar beeps, and heavy explosion booms on the fly.
- **⚡ Auto-Blast Looping Mode:** Automated firing sequence for hands-free showcase.

### 🎥 3D Project Visuals (Higgsfield AI)
- **Hero Banner (`hero_animation.mp4`):** Seamless looping 3D cloud server and neural network architecture.
- **Local AI Pipeline (`local_ai_pipeline.mp4`):** Isometric M1 edge computing processing video streams into local intelligence.
- **Campus Found (`campus_found_arch.mp4`):** AWS EKS Kubernetes cluster routing traffic through Gemini AI verification.

---

## 🛠️ Tech Stack
- **Styling:** HTML5, Tailwind CSS, Custom CSS Keyframe Animations
- **Game Engine & Physics:** Vanilla JavaScript (ES6+), HTML5 Canvas 2D Context, Web Audio API
- **Visual Assets:** Higgsfield AI Video Generation (Seedance models)
